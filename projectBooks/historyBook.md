## 📊 버전 이력

### v0.4.0 (2026-01-16) - 탄약 + 재장전 시스템

#### 🎯 주요 변경사항

| 카테고리 | 내용 |
|---------|------|
| **탄약 관리** | 슬롯별 장탄수 + 탄약 타입별 보유량 시스템 |
| **재장전** | R키 수동 재장전, 자동 재장전 없음 |
| **샷건 특수** | 한 발씩 순차 재장전 (탄당 500ms) |
| **재장전 취소** | R키 재입력으로 재장전 즉시 취소 |
| **행동 제한** | 재장전 중 발사/무기변경 불가 |
| **UI** | 우측 하단 무기 상태, 중앙 재장전 인디케이터 |

#### 📁 추가/수정된 파일

```
packages/client/src/game/
├── input/InputManager.ts     # R키 입력 추가
└── core/
    ├── Game.ts               # 탄약 상태, 재장전 로직
    └── Renderer.ts           # drawWeaponStatus(), drawReloadIndicator()

projectBooks/
└── futureBook.md             # 재장전 중 달리기 불가 기록
```

#### 🎮 구현된 기능

| 기능 | 설명 |
|------|------|
| 장탄수 관리 | 발사 시 탄약 소모, 빈 탄창 시 발사 불가 |
| 보유 탄약 | 탄약 타입별 별도 관리 (4mm, 9mm, shotgun) |
| R키 재장전 | 수동 재장전만 지원, 자동 재장전 없음 |
| 재장전 조건 | 최대 장탄 미만 + 보유 탄약 1 이상 |
| 샷건 순차 장전 | 한 발씩 장전, 중간 취소 가능 |
| 재장전 취소 | R키 재입력 시 즉시 취소 |
| 재장전 중 제한 | 발사 불가, 무기 변경 불가 |

#### 🖥️ UI 추가

| UI 요소 | 위치 | 설명 |
|---------|------|------|
| 무기 이름 (탄환) | 우측 하단 | 볼드 18px, 투명 배경 |
| 장탄수 / 보유량 | 우측 하단 | 24px 장탄수 + 16px 보유량 |
| 재장전 원 | 화면 중앙 | 희미한 원형 프로그레스 + "재장전" 텍스트 |

#### 📝 추후 구현 예정

| 항목 | 상태 | 설명 |
|------|------|------|
| 재장전 중 달리기 불가 | 기록됨 | 달리기 시스템 구현 시 적용 |

### v0.3.0 (2026-01-16) - 무기 + 전투 시스템

#### 🎯 주요 변경사항

| 카테고리 | 내용 |
|---------|------|
| **무기 정의** | WeaponDef 인터페이스, 3종 무기 (권총, 소총, 샷건) |
| **투사체 시스템** | Projectile 엔티티, 벽 충돌 시 소멸, 무한 사거리 |
| **무기 슬롯** | 5슬롯 시스템, 마우스 휠/숫자키(1-5) 선택 |
| **발사 메커니즘** | 단발/자동 모드, 스프레드, 연사속도 제어 |
| **HUD** | 무기 슬롯 UI (하단 중앙), 현재 선택 표시 |

#### 📁 추가/수정된 파일

```
packages/shared/src/
├── types/weapon.ts           # WeaponDef, AmmoType, WeaponCategory
└── constants/weapons.ts      # WEAPONS 데이터, PROJECTILE_CONFIG

packages/client/src/game/
├── entities/Projectile.ts    # 투사체 엔티티 (이동, 보간, 데미지 계산)
├── input/InputManager.ts     # 휠/숫자키 입력 추가
└── core/
    ├── Game.ts               # 무기 슬롯, 발사 로직, 투사체 관리
    └── Renderer.ts           # drawProjectile(), drawWeaponSlots()
```

#### 🎮 구현된 기능

| 기능 | 설명 |
|------|------|
| 마우스 클릭 발사 | 좌클릭으로 현재 무기 발사 |
| 무기 선택 | 휠 스크롤 또는 1-5 키 |
| 투사체 물리 | 속도 기반 이동, 벽 충돌 감지 |
| 스프레드 | 단발: 랜덤 스프레드, 샷건: 균등 분포 |
| 연사 제어 | RPM 기반 발사 간격 |
| 단발/자동 | 권총/샷건: 클릭마다, 소총: 홀드 연사 |

#### 🔫 무기 데이터

| 무기 | 슬롯 | 데미지 | 연사 | 탄속 | 특징 |
|------|------|--------|------|------|------|
| 프로토타입 | 1 | 25 | 300 RPM | 800 | 권총, 단발 |
| 돌격 소총 | 2 | 35 | 600 RPM | 1000 | 자동 연사 |
| 펌프 샷건 | 3 | 15×8 | 60 RPM | 700 | 8발 산탄 |

#### 🎨 투사체 렌더링

| 요소 | 설명 |
|------|------|
| 모양 | 황금색 타원 (진행 방향) |
| 트레일 | 그라데이션 꼬리 효과 |
| 글로우 | 발광 효과 |

### v0.2.0 (2026-01-16) - 타일 기반 맵 + 충돌 시스템

#### 🎯 주요 변경사항

| 카테고리 | 내용 |
|---------|------|
| **타일 시스템** | TileType enum (EMPTY, FLOOR, WALL, HALF_WALL, DOOR, WINDOW) |
| **맵 데이터** | GameMap 인터페이스, 64x64 타일 (2048x2048px) |
| **충돌 시스템** | 원형 충돌체-타일 AABB 충돌 + 밀어내기 |
| **테스트 맵** | 5개 건물 + 반벽 장애물 + 32개 스폰 포인트 |

#### 📁 추가/수정된 파일

```
packages/shared/src/
├── types/map.ts              # 타일 타입, 맵 인터페이스, 좌표 변환
└── constants/map.ts          # 타일 색상, 맵 상수, createTestMap()

packages/client/src/game/
├── world/TileMap.ts          # 타일맵 관리 + 충돌 판정
└── core/
    ├── Game.ts               # TileMap 연동, 충돌 처리 추가
    └── Renderer.ts           # drawTileMap() 추가
```

#### 🎮 구현된 기능

| 기능 | 설명 |
|------|------|
| 타일 기반 맵 | 64x64 타일, 각 32x32px |
| 타일 종류 | 바닥, 벽, 반벽, 문, 창문 |
| 건물 | 벽으로 둘러싸인 방 + 문/창문 |
| 벽 충돌 | AABB 충돌 감지 + 밀어내기 |
| 스폰 시스템 | 맵 외곽 32개 스폰 포인트 |
| 최적화 렌더링 | 카메라 범위 내 타일만 렌더링 |

#### 🎨 디버그 색상

| 문 | #8b5a2b (갈색) |

### v0.1.0 (2026-01-16) - 최초 개발 환경 구축

#### 🎯 주요 변경사항

| 카테고리 | 내용 |
|---------|------|
| **프로젝트 구조** | npm workspaces 기반 모노레포 구축 (client/server/shared) |
| **클라이언트** | React 18 + Vite 5 + TypeScript 기반 게임 클라이언트 |
| **게임 코어** | Canvas 2D 렌더러, 게임 루프 (20Hz/60fps), 입력 시스템 |
| **서버** | WebSocket 서버 기본 구조 (Node.js + ws) |

#### 📁 생성된 파일

```
battleRoyal_2d/
├── package.json                    # npm workspaces 루트
├── tsconfig.json                   # TypeScript 공용 설정
├── .gitignore
├── README.md
│
├── packages/
│   ├── shared/                     # 공유 코드
│   │   ├── package.json
│   │   ├── tsconfig.json
│   │   └── src/
│   │       ├── index.ts
│   │       ├── types/              # 타입 정의 (game, player, network)
│   │       ├── constants/          # 게임 상수 (설정, 색상)
│   │       ├── utils/              # 유틸리티 (Vector2, 충돌)
│   │       └── protocol/           # 네트워크 프로토콜
│   │
│   ├── client/                     # React 클라이언트
│   │   ├── package.json
│   │   ├── tsconfig.json
│   │   ├── vite.config.ts
│   │   ├── index.html
│   │   └── src/
│   │       ├── main.tsx
│   │       ├── App.tsx
│   │       ├── vite-env.d.ts
│   │       ├── styles/global.css
│   │       ├── components/screens/ # MainMenu, GameScreen
│   │       └── game/
│   │           ├── core/           # Game, GameLoop, Renderer
│   │           ├── entities/       # Player
│   │           ├── input/          # InputManager
│   │           └── world/          # Camera
│   │
│   └── server/                     # 게임 서버
│       ├── package.json
│       ├── tsconfig.json
│       └── src/index.ts            # WebSocket 서버
```

#### 🎮 구현된 기능

| 기능 | 설명 |
|------|------|
| 게임 루프 | 20Hz 고정 업데이트 + 60fps 렌더링 + 보간 |
| 플레이어 이동 | WASD/화살표 키 8방향 이동 |
| 마우스 조준 | 마우스 위치로 플레이어 회전 |
| 카메라 | 플레이어 추적 + 부드러운 이동 (lerp) |
| 디버그 렌더링 | 원형 플레이어, 그리드, 맵 경계 |
| 맵 경계 | 2000x2000px 맵, 경계 충돌 |

#### 🔧 기술 스택

| 구분 | 선택 |
|------|------|
| 클라이언트 | React 18, Vite 5, TypeScript 5, Zustand |
| 렌더링 | HTML5 Canvas 2D |
| 서버 | Node.js 20+, ws (WebSocket) |
| 빌드 | npm workspaces (모노레포) |
