### v0.8.2 (2026-01-17) - AI 시야 시스템 (Line of Sight)

#### 🎯 주요 변경사항

| 카테고리 | 내용 |
|---------|------|
| **시야 체크 (LoS)** | AI가 벽 뒤의 적을 탐지하지 못함 |
| **사격 전 LoS 확인** | 벽이 막고 있으면 사격 안함, 추적으로 전환 |
| **레이캐스팅** | 8px 간격으로 벽 충돌 체크 |

#### 📁 수정된 파일

```
packages/client/src/game/ai/
└── BotAI.ts              # hasLineOfSight(), findVisibleEnemy() LoS 추가
```

#### 🎮 구현된 기능

| 기능 | 설명 |
|------|------|
| hasLineOfSight() | 두 점 사이 벽 존재 여부 체크 |
| 적 탐지 LoS | 시야 범위 내에 있어도 벽 뒤면 탐지 불가 |
| 공격 중 LoS | 시야 막히면 CHASE 상태로 전환 |

#### 🐛 수정된 버그

| 버그 | 해결 |
|------|------|
| 벽 뒤 적 즉시 탐지 | LoS 체크로 벽 통과 탐지 방지 |
| 벽 향해 무한 사격 | 시야 막히면 추적으로 전환 |

### v0.7.0 (2026-01-17) - AI 봇 시스템


|------|------|------|

| CHASE | 추적 | 적 따라가기 |

| FLEE | 도주 | 적 반대 방향으로 도망 |

|--------|--------|------|----------|----------|
| Easy | 40% | 300px | ×1.5 | 20% |
| Normal | 70% | 450px | ×1.0 | 25% |
| Hard | 90% | 600px | ×0.8 | 30% |

#### 🐛 수정된 버그

| 버그 | 해결 |
|------|------|
| AI 사격 안됨 | 무기 ID 오타 수정 (proto_pistol → pistol_proto) |

### v0.6.1 (2026-01-17) - 버그 수정

#### 🐛 수정된 버그

| 버그 | 원인 | 해결 |
|------|------|------|
| 벽 근접 시 사격 효과 미표시 | 총구 위치가 벽 안에 있으면 즉시 충돌 | 시작 위치가 벽 안이면 플레이어 중심에서 발사 |
| 투사체가 벽 도달 전 사라짐 | 렌더링 보간 위치 ≠ 충돌 체크 위치 | 충돌 시 투사체를 충돌 직전 위치로 이동 후 제거 |
| 무기 UI 간격 부족 | 이름-숫자 간격이 너무 좁음 | 세로 15px, 가로 10px 간격 증가 |

#### 📁 수정된 파일

```
packages/client/src/game/core/
├── Game.ts         # fire() 시작 위치 체크, checkProjectileWallCollision() 충돌 지점 반환
└── Renderer.ts     # drawWeaponStatus() 간격 조정
```

#### 🔧 기술적 개선

| 항목 | 변경 |
|------|------|
| 투사체 충돌 샘플링 | 8px → 4px (더 정밀) |
| 충돌 함수 반환값 | `boolean` → `{ hit, x, y }` |
