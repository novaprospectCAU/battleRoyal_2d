## 📌 이 문서의 목적

이 문서는 `projectBooks` 폴더 내 모든 문서(Book)들의 **색인이자 안내서**입니다.  
어떤 정보가 어디에 있는지 찾을 때, 새로운 문서를 작성할 때 이 가이드를 참조하세요.

## 🗺️ 문서 조회 순서 가이드

### 프로젝트 처음 참여 시
```
blueprint.md → guideBook.md → ruleBook.md → specBook.md
```

### 특정 주제 탐색 시
```
guideBook.md → 해당 Book → 관련 Book들
```

### 기능 개발 전
```
blueprint.md → 해당 기능 관련 Book들 → codeBook.md → testBook.md
```

## 📝 새 문서 작성 가이드

### 문서 작성 원칙
1. **명확한 목적**: 각 문서는 하나의 명확한 주제를 다룸
2. **독립적 이해**: 해당 문서만 읽어도 주제를 이해할 수 있게
3. **상호 참조**: 관련 문서는 링크로 연결
4. **버전 관리**: 상단에 버전과 날짜 명시
5. **변경 이력**: 중요 변경은 문서 하단에 기록

### 문서 템플릿
```markdown
# 📖 [문서명] - [한줄 설명]

> **최초 작성일**: YYYY-MM-DD  
> **마지막 수정**: YYYY-MM-DD  
> **버전**: X.Y.Z
```
