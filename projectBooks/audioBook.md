# 🔊 AudioBook - 오디오 명세서

> **최초 작성일**: 2026-01-14  
> **마지막 수정**: 2026-01-14  
> **버전**: 0.1.0

## 📌 이 문서의 목적

이 문서는 게임의 **효과음, 배경음악, 음향 효과의 종류, 재생 조건, 볼륨, 스펙**을 정의합니다.

---

## 🎯 핵심 원칙

### 오디오 독립성
```
artBook과 동일하게:
- 오디오 없이도 게임 동작
- 디버그 모드: 콘솔 로그로 대체 또는 무음
- 프로덕션 모드: 실제 사운드 재생
```

### 공간 오디오
```
2D 공간 기반 사운드:
- 거리에 따른 볼륨 감쇠
- 방향에 따른 패닝 (좌/우)
- 소음 시스템과 연계 (다른 플레이어가 들을 수 있음)
```

## 📁 오디오 카테고리

### 분류

| 카테고리 | 설명 | 예시 |
|----------|------|------|

## 📐 오디오 스펙

### 파일 형식

| 용도 | 형식 | 이유 |
|------|------|------|
| **SFX** | MP3 / OGG | 짧은 효과음, 호환성 |
| **BGM** | MP3 | 스트리밍, 용량 |
| **UI** | WAV / MP3 | 즉시 재생 필요 |

### 샘플 레이트

```
권장: 44.1kHz, 16bit
SFX: 모노 (공간 오디오 적용)
BGM: 스테레오
```

### 파일 크기 가이드

| 종류 | 길이 | 예상 크기 |
|------|------|----------|
| SFX (짧은) | 0.1-0.5초 | 5-20KB |
| SFX (중간) | 0.5-2초 | 20-80KB |
| BGM | 2-4분 | 2-5MB |
| Ambient (루프) | 10-30초 | 100-500KB |

## 📍 공간 오디오

### 거리 기반 볼륨

```typescript
function calculateVolume(
  sourcePos: Position,
  listenerPos: Position,
  maxDistance: number,
  baseVolume: number
): number {
  const distance = getDistance(sourcePos, listenerPos);
  
  if (distance >= maxDistance) {
    return 0;
  }
  
  // 선형 감쇠 (또는 지수 감쇠)
  const attenuation = 1 - (distance / maxDistance);
  return baseVolume * attenuation;
}
```

### 스테레오 패닝

```typescript
function calculatePan(
  sourcePos: Position,
  listenerPos: Position,
  listenerDirection: number
): number {
  // -1 (왼쪽) ~ 0 (중앙) ~ 1 (오른쪽)
  const angle = getAngle(listenerPos, sourcePos) - listenerDirection;
  return Math.sin(angle);
}
```

```
소음 발생 시:
```
