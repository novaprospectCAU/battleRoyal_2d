## 🌍 맵 개요

### 맵 크기
```
[논의 필요: 맵 크기]

고려 사항:
- 32명 플레이어 수용
- 10단계 자기장 (약 8-10분 게임)
- 쿼터뷰 시점에서의 가시성

예상 크기: 1600 x 1600 ~ 4000 x 4000 픽셀? : 일단은 2000 X 2000으로 하자
(1 타일 = 32px 기준, 약 100x100 ~ 150x150 타일) : 일단 플레이어 캐릭터 기준으로 가로 세로 2배한 정사각형이 한 타일이 되도록 하자
```

### 맵 형태
```
[논의 필요: 맵 형태]

옵션 A: 정사각형 (단순, 자기장 계산 쉬움) : 일단 정사각형으로 하고, 이동, 파괴 불가한 벽으로 타일들을 둘러싸는 형태로 
옵션 B: 원형 (배틀로얄 느낌, 모서리 데드존 없음) : 차후
옵션 C: 불규칙 (섬, 도시 등 테마에 맞춤) : 차후
```

### 맵 테마
```
[논의 필요: 맵 테마]

이거는 에셋을 보고 결정하자

후보:
- 폐허가 된 도시
- 군사 기지
- 섬/해안가
- 숲 + 마을
- 산업 단지
- 혼합 (중앙 도시 + 외곽 자연)
```

## 🏢 건물 및 구조물

### 건물 유형

#### 1. 소형 건물
| 종류 | 크기 | 룸 수 | 루팅 포인트 | 엄폐물 |
|------|------|-------|------------|--------|
| 오두막 | 3x3 타일 | 1 | 2-3 | 연질 (나무) |
| 창고 | 4x3 타일 | 1 | 3-4 | 중질 |
| 초소 | 2x2 타일 | 1 | 1-2 | 경질 |

#### 2. 중형 건물

- 이거는 나중에 랜덤한 포맷으로 뽑아낼 수 있도록 하는게 좋을거 같아.
- 그리고 2D 쿼터뷰 한계상 층고는 없고, 1층만 있어야 하고, 각 건물에는 문과 창문이 있을 수 있고,
- 문의 경우는 닫혀있으면 시야가 막히고, 관통이 가능한 연질이고, 
- 창문은 기본적으로 창문에 커서를 대고 있어야 밖에서 제한적으로 안을 볼수 있고,
- 집 안 창문에 있는 경우는 바깥의 시야가 그대로 보여. 단, 창문으로는 100% 데미지를 받거나 줄 수 있어야 해.
- 그리고, 창문과 낮은 돌담은 짧은 시간 애니메이션을 통해 반대편으로 넘어갈 수 있지만, 그 동안 공격이나 이동이 불가해.
- 열린 문, 창문, 낮은 돌담으로는 투척물이 도달할 수 있고, 담의 경우는 높게 던지는 경우만 도달 할 수 있어.
- (투척물 들고 우클릭을 통해서 높게 가까이 던질지, 낮게 멀리 던질지 선택할 수 있고, 들고 있는동안 게이지가 차면서 언제 폭발할지 볼 수 있고,
- 게이지가 다 차면 폭발해. )

- 기본적으로 타일은 사이즈가 거의 플레이어가 있는 곳의 사이즈만하니, 좀 더 크게 잡아야 할 거 같아.

| 종류 | 크기 | 룸 수 | 루팅 포인트 | 엄폐물 |
|------|------|-------|------------|--------|
| 주택 | 5x5 타일 | 3-4 | 5-8 | 중질 |
| 상점 | 4x6 타일 | 2 | 4-6 | 중질 |
| 사무실 | 6x6 타일 | 4-6 | 6-10 | 중질~경질 |

#### 3. 대형 건물
| 종류 | 크기 | 룸 수 | 루팅 포인트 | 엄폐물 |
|------|------|-------|------------|--------|
| 아파트 | 8x8 타일 | 8-12 | 10-15 | 경질 |
| 공장 | 10x8 타일 | 3-5 | 8-12 | 경질 (금속) |
| 학교/병원 | 12x10 타일 | 10+ | 15-20 | 경질 |

### 건물 내부 구성

- 그리고 일반 주택같이 중형 이상의 건물은 무조건 입구가 2개 혹은 3개여야 해.
```
[일반 주택 예시]

┌─────────────────┐
│     거실        │  ← 루팅 포인트 1-2개
│    ┌────┐       │
│    │테이블│      │  ← 엄폐물 (중질)
│    └────┘       │
├────────┬────────┤
│ 방1    │ 방2    │  ← 각 방에 루팅 포인트 1-2개
│        │        │
│ [침대] │ [책상] │  ← 엄폐물 (연질~중질) : 이거는 창문이 될 수도 있어
└────────┴────────┘
     ▲
   출입구
```

## 📍 스폰 시스템

### 플레이어 스폰

```
[논의 필요: 스폰 방식]

- 일단은 옵션 A로 해보고 결정하자

옵션 A: 맵 외곽 랜덤 스폰
- 모든 플레이어가 맵 가장자리에서 시작
- 초반 교전 적음, 루팅 시간 확보

옵션 B: 전체 맵 랜덤 스폰
- 어디서든 시작 가능
- 초반부터 긴장감

옵션 C: 지정된 스폰 포인트
- 균등하게 배치된 32개 스폰 지점
- 공정한 시작 거리

권장: 옵션 C (32개 균등 배치)
```

### 스폰 포인트 배치 예시
```
     ·  ·  ·  ·  ·  ·  ·  ·
   ·                        ·
  ·    ┌──────────────┐      ·
 ·     │              │       ·
·      │     맵      │        ·
·      │              │        ·
 ·     │              │       ·
  ·    └──────────────┘      ·
   ·                        ·
     ·  ·  ·  ·  ·  ·  ·  ·

· = 스폰 포인트 (맵 외곽에 균등 배치)
```

### 스폰 규칙
- 최소 거리: 다른 스폰 포인트와 일정 거리 이상
- 시야 차단: 스폰 직후 다른 플레이어 안 보임
- 건물 근처: 최소 1개 건물 접근 가능

- 맵 생성 로직이 일단 건물이 4 ~ 16타일 이내에 플레이어가 도달할 수 있도록 하는 게 좋을 거 같아.

## 📦 아이템 스폰

### 스폰 위치 규칙
```
✅ ruleBook에서 결정됨:
- 되도록 실내에서 랜덤한 위치에 배치
- 완전 무작위 (등급별 차등은 차후)
```

### 스폰 포인트 타입

| 타입 | 위치 | 아이템 종류 |
|------|------|------------|
| **바닥** | 건물 내부 바닥 | 무기, 탄약, 회복 |
| **테이블** | 가구 위 | 부착물, 소형 아이템 |
| **상자** | 특정 컨테이너 | 랜덤 (확률 높음) |
| **야외** | 건물 외부 (드묾) | 탄약, 회복 (낮은 등급) |

### 아이템 밀도

- 이거는 차후에 결정

| 지역 | 스폰 포인트/100타일 | 예상 아이템 |
|------|-------------------|------------|
| 도심 | 15-20 | 좋은 무기 확률 높음 |
| 주거지 | 10-15 | 균형 잡힌 분포 |
| 외곽 | 5-8 | 기본 아이템 위주 |
| 특수 지역 | 25+ | 고급 무기/부착물 |

## 🧱 엄폐물 시스템

### 엄폐물 종류 (ruleBook 연계)

| 타입 | 예시 | 관통 | 크기 |
|------|------|------|------|
| **연질 (Soft)** | 나무 울타리, 덤불, 박스 | 대부분 관통 | 소~중 |
| **중질 (Medium)** | 책상, 차량, 나무 기둥 | 일부 관통 | 중 |
| **경질 (Hard)** | 콘크리트, 금속 컨테이너 | 거의 불가 | 중~대 |
| **완전 (Solid)** | 건물 벽, 지형 | 완전 차단 | - |

### 엄폐물 배치 원칙
```
1. 이동 경로에 적절한 간격으로 배치
   - 외곽: 30-50 타일 간격
   - 도심: 5-10 타일 간격

2. 교차 사격 가능한 구조
   - 완전한 안전지대 최소화
   - 여러 방향에서 공격 가능하도록

3. 리스크-리워드
   - 좋은 엄폐물 = 루팅 적음
   - 루팅 많은 곳 = 노출 위험
```

## 🚗 이동 및 경로

- 아직은 차량이나 탈 것은 생각하지 말고, 일단은 플레이어가 직접 이동하는 것만 있다고 생각해

### 도로/경로 시스템
```
[논의 필요: 도로 시스템]

옵션 A: 격자형 도로 (도시)
옵션 B: 자연스러운 경로 (숲/시골)
옵션 C: 혼합

도로 특성:
- 빠른 이동 가능
- 엄폐물 없음 (노출 위험)
- 차량 배치 가능 (엄폐물로 활용)
```

### 지형 고저차
```
[논의 필요: 고저차 도입 여부]

2D 쿼터뷰에서의 고저차:
- 시각적 표현 가능 (언덕, 경사)
- 게임플레이 영향은 제한적

옵션 A: 평면만 (단순)
옵션 B: 2단계 높이 (1층/2층 개념)
옵션 C: 연속적 고저차 (복잡)

권장: 옵션 B (건물 내 층 개념만)
```

## 🔵 자기장과 맵

### 자기장 중심점
```
[논의 필요: 자기장 알고리즘]

옵션 A: 완전 랜덤 (현재 구역 내 아무 곳)
옵션 B: 가중치 랜덤 (랜드마크 쪽으로 편향)
옵션 C: 플레이어 분포 고려 (균형)

권장: 옵션 A (단순, 예측 불가)

- 단, 옵션 A로 생각하고 개발하되, 원 안에 무조건 직전 페이즈 인원 수 / 2 이상이 들어가도록 하고,
- 최초 페이즈에서는 무조건 현재 살아있는 인원수의 80% 이상이 들어가도록 해야 해.
```

### 자기장 시각화
- 미니맵에 현재 구역 표시 (흰색 원)
- 다음 구역 표시 (파란색/다른 색 원)
- 자기장 외부는 색상 변화 (붉은 색조?) : 단, 자기장 자체는 붉은 빛이 돌아야 하지만, 자기장의 경계만 색상을 주고
- 자기장 밖에 있는 사람은 화면 전체가 아주 조금 붉게 되어야 해. (한 opacity : 0.1정도?)

## 📐 타일 시스템

### 기본 타일
```
타일 크기: 32 x 32 픽셀 (예상) : 이거 플레이어의 가로 X 2사이즈를 한 변으로 정사각형으로 생각해줘.

타일 종류:
- 지면 (잔디, 흙, 아스팔트, 타일 등)
- 벽 (완전 차단)
- 반벽 (높이 절반, 일부 차단) : 넘어갈 수 있고, 낮게 던져도 투척물이 넘어갈 수 있지만, 총알은 닿지 못하도록 
- 문 (열림/닫힘)
- 창문 (시야 통과, 이동 가능) 
```

### 충돌 레이어
```
Layer 0: 지면 (이동 가능)
Layer 1: 엄폐물 (충돌, 관통 판정)
Layer 2: 벽 (완전 차단)
Layer 3: 장식 (충돌 없음)
```

## 🎯 맵 데이터 구조

### 맵 파일 형식 (예상)
```typescript
interface GameMap {
  name: string;
  size: { width: number; height: number };  // 타일 단위
  tileSize: number;  // 픽셀
  
  // 레이어별 타일 데이터
  layers: {
    ground: number[][];    // 지면 타일 ID
    collision: number[][]; // 충돌/엄폐물
    decoration: number[][]; // 장식
  };
  
  // 스폰 포인트
  playerSpawns: Position[];
  itemSpawns: ItemSpawn[];
  
  // 지역 정보
  regions: Region[];
  
  // 자기장 설정
  zoneSettings: ZoneSettings;
}

interface ItemSpawn {
  position: Position;
  type: 'floor' | 'table' | 'crate';
  tier: 'low' | 'medium' | 'high';  // 차후 사용
}

interface Region {
  name: string;
  bounds: Rectangle;
  type: 'urban' | 'residential' | 'outskirts' | 'special';
  itemDensity: number;
}
```
