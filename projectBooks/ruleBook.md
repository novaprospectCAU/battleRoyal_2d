## 📌 이 문서의 목적

이 문서는 게임의 **모든 규칙과 메카닉**을 정의합니다.  
플레이어 관점(어떻게 플레이하는가)과 관리자 관점(어떻게 운영하는가) 모두를 포함합니다.

> ⚠️ `[논의 필요]` 태그가 붙은 항목은 추후 결정이 필요한 사항입니다.

## 🎯 게임 개요

### 한 줄 설명
> 최대 32명의 플레이어가 축소되는 맵에서 최후의 1인(또는 1팀)이 될 때까지 싸우는 2D 쿼터뷰 배틀로얄

### 핵심 목표
- **생존**: 마지막까지 살아남기
- **처치**: 다른 플레이어 제거
- **루팅**: 맵에서 무기/아이템 획득
- **이동**: 축소되는 안전 구역 내 유지

## 🔄 게임 흐름

### 전체 흐름도
```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  로비   │ → │  매칭   │ → │ 준비단계 │ → │ 게임진행 │ → │  결과   │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
```

### 1. 로비 (Lobby)
- 플레이어가 게임에 접속하는 초기 화면
- 게임 모드 선택 (솔로/듀오/스쿼드)
- 매칭 대기열 참가
- 캐릭터 커스터마이징 `[논의 필요: 커스터마이징 범위]`

### 2. 매칭 (Matchmaking)
- 플레이어 수 충족 시 게임 시작
- **최소 인원**: `[논의 필요]` (예: 8명?)
- **최대 인원**: 32명
- **대기 시간**: `[논의 필요]` (예: 최대 60초?)
- 인원 미달 시 AI 봇으로 채움 `[논의 필요: 봇 비율 제한?]`

### 3. 준비 단계 (Pre-Game)
- **카운트다운**: `[논의 필요]` (예: 5초?)
- 맵 전체 조감 또는 스폰 위치 표시
- 모든 플레이어 동시 스폰

### 4. 게임 진행 (In-Game)
- 루팅, 전투, 이동의 반복
- 자기장(안전 구역) 점진적 축소
- 생존자 수 실시간 표시

### 5. 결과 (End-Game)
- 최종 순위 표시
- 킬/데미지 통계
- `[논의 필요: 보상 시스템?]`

### 데미지 계산

#### ✅ 스윗스팟 시스템 (배틀필드1 스타일)

각 무기는 **최적 거리(Sweet Spot)**가 있으며, 해당 거리에서 최대 데미지를 발휘합니다.

```
데미지 곡선 예시 (소총):

데미지
  │
100├─────────╮
  │         ╲
 80├──╮      ╲
  │  │       ╲
 60├  │        ╲
  │  │         ╲
 40├──┴──────────╲────────
  │
  └──┬──┬──┬──┬──┬──┬──► 거리
     0  50 100 150 200 250

     ↑        ↑
   근거리   스윗스팟
   감쇠     (최대 데미지)
```

#### 거리별 데미지 공식
```typescript
function calculateDamage(weapon: Weapon, distance: number, cover: Cover | null): number {
  // 1. 스윗스팟 기반 거리 데미지
  let damage = weapon.baseDamage * getDistanceMultiplier(weapon, distance);
  
  // 2. 엄폐물 관통 적용
  if (cover) {
    damage = applyCoverPenetration(damage, weapon, cover);
  }
  
  // 3. 방어구 적용 (채택 시)
  // damage = applyArmor(damage, target);
  
  return Math.floor(damage);
}

function getDistanceMultiplier(weapon: Weapon, distance: number): number {
  const { minRange, sweetSpotStart, sweetSpotEnd, maxRange } = weapon;
  
  if (distance < minRange) {
    // 너무 가까움 (샷건 제외)
    return weapon.closeRangeMultiplier; // 예: 0.6 ~ 0.8
  }
  if (distance >= sweetSpotStart && distance <= sweetSpotEnd) {
    // 스윗스팟! 최대 데미지
    return 1.0;
  }
  if (distance > sweetSpotEnd && distance <= maxRange) {
    // 스윗스팟 이후 감쇠
    const falloff = (distance - sweetSpotEnd) / (maxRange - sweetSpotEnd);
    return 1.0 - (falloff * weapon.falloffRate); // 예: 0.4 ~ 0.7
  }
  // 최대 사거리 초과
  return weapon.minDamageMultiplier; // 예: 0.3
}
```

#### 무기별 스윗스팟 범위 (예시)

| 무기 | 기본 데미지 | 스윗스팟 거리 | 근거리 배율 | 원거리 최소 배율 |
|------|------------|--------------|------------|-----------------|
| 주먹 | 10 | 0-30 | 1.0 | 0 (사거리 없음) | // 근거리 무기는 사용하지 않을 예정, 총, 투척류만 존재할 예정
| 샷건 | 80 (탄환당) | 0-50 | 1.0 | 0.2 |
| 권총 | 25 | 30-80 | 0.7 | 0.5 |
| SMG | 18 | 20-100 | 0.8 | 0.4 |
| 소총 | 35 | 80-180 | 0.6 | 0.5 |
| 스나이퍼 | 90 | 150-300 | 0.4 | 0.6 |

일단 무기는 주무기 2개 + 부무기 1개가 존재하는데, 샷건은 모두 동일한 탄을 사용
총 샷건 탄환 / 4탄 / 5탄 / 7탄 / 9탄이 존재하고, 4탄은 대체로 권총탄, 5탄은 SMG ~ 소총, 7탄은 소총 ~ MG, 9탄은 소총 ~ 저격총으로 경향성을 가짐

주무기
1. 더블배럴 샷건(샷건) : 매우 강력한 두발의 탄이 날라가는 형태, 초근~근거리 정확도와 데미지가 매우 높지만, 중거리 이상에서는 정확도가 낮고, 데미지가 절반으로 감소, 한 번쏘면 짧은 재장전 시간 필요 (발당 탄 2개 소모)
2. 불펍식 샷건(샷건) : 다른 샷건들과 달리 많은 장탄수와 상대적으로 빠른 재장전 시간, 샷건 발사시 한 번에 6개의 탄환(탄 수는 1개 소모)이 넓은 반경으로 발사, 중거리 이하에서 높은 데미지를 주고, 상대적으로 빠른 연사 속도를 가짐. 원거리는 데미지가 매우 감소 (장탄 수 12발)
3. 펌프 샷건(샷건) : 적당히 많은 장탄수와 제일 빠른 연사 속도를 가짐. 샷건 발사시 한 번에 좁은 반경으로 8개의 탄환(탄 수는 1개 소모) 발사, 각 탄환은 낮은 데미지지만 8개를 다 맞으면 중거리 내에서 100이 넘는 데미지. 단, 재장전 속도가 느리고, 탄을 하나하나 추가하는 형태. 단, 재장전 키를 다시 누르면 재장전 취소하고 바로 발사 가능 (장탄 수 6발)
4. 마이크로 SMG(SMG - 5탄) : 매우 빠른 탄속과 매우 빠른 연사 속도, 빠른 재장전 속도를 가지지만, 근거리 내에서 낮은 데미지, 중거리 이상에서는 낮은 명중률과 매우 낮은 데미지 (장탄 수 20발)
5. 파이프 SMG(SMG - 5탄) : 매우 빠른 탄속과 빠른 연사 속도, 적당한 재장전 속도를 가지고, 근거리 내에서 적당한 데미지, 중거리까지는 정확도가 높으나 중거리 이상에서는 매우 낮은 데미지 (장탄 수 30발)
6. 기계식 기관단총(SMG - 7탄) : 빠른 탄속과 조금 빠른 연사 속도, 빠른 재장전 속도를 가지고, 중거리까지 적당한 데미지, 적당한 정확도가 있으나, 낮은 장탄 수 보유 (장탄 수 16발)
7. 카빈(소총 - 5탄) : 단발로만 쏠 수 있지만, 높은 정확도, 중거리에서 높은 데미지, 나머지에서는 적당한 데미지를 줄 수 있는 다목적 소총, 적당한 재장전 속도 및 낮은 연사 속도 (장탄 수 12발)
8. 돌격 소총(소총 - 9탄) : 단발 / 연발로 쏠 수 있고, 근~중거리에서 높은 데미지, 나머지에서는 적당한 데미지를 줄 수 있고, 조금 빠른 재장전 속도와 적당한 연사 속도를 갖지만, 연발에서의 낮은 정확도(단, 패턴 존재), 큰 소음이 발생 (장탄 수 30발)
9. 자동 소총(소총 - 7탄) : 단발 / 연발로 쏠 수 있고, 중거리~원거리에서 높은 데미지, 나머지에서는 적당한 데미지를 줄 수 있고, 조금 빠른 재장전 속도와 빠른 연사 속도를 갖지만, 연발에서는 낮은 정확도(단, 패턴 존재), 돌격 소총보다 데미지가 약간 낮음 (장탄 수 28발)
10. 불펍 소총(소총 - 7탄) : 단발 / 3점사로 쏠 수 있고, 3점사는 매우 빠른 연사속도지만, 3발 발사후 약간의 텀이 존재, 근~중거리에서 높은 데미지, 나머지에서는 낮은 데미지를 줄 수 있고, 빠른 재장전 속도와 높은 정확도를 가지지만, 연사가 불가 (장탄 수 28발)
11. 지정사수 소총(소총 - 5탄) : 단발 / 연발로 쏠 수 있고, 초탄은 매우 정확하고 전체적으로 높은 정확도와 적당한 데미지를 줄 수 있음(패턴 존재). 연사속도도 적당하지만 조금 느린 재장전 속도를 가지고, 초근거리에서는 낮은 데미지를 줌. (장탄 수 34발)
12. 중형 기관총(MG - 7탄) : 연발로 쏠 수 있고, 초탄은 적당한 정확도를 가지지만, 나머지는 낮은 정확도와 큰 소음이 발생. 매우 느린 재장전 속도를 가지지만, 매우 높은 연사 속도와 중거리 안에서는 적당한 데미지를 줌. (장탄 수 80발)
13. 지원 기관총(MG - 9탄) : 연발로 쏠 수 있고, 중형 기관총보다 전체적으로 높은 정확도를 가지고, 조금 적은 소음이 발생하고, 적당한 재장전 속도를 가지지만, 중형 기관총보다 낮은 연사 속도와 적은 장탄 수를 가짐. (장탄 수 48발)
14. 자동 기관총(MG - 5탄) : 3점사 / 연발로 쏠 수 있고, 매우 빠른 연사 속도와 모든 거리에서 높은 데미지를 가지지만, 낮은 정확도와 매우 느린 재장전 속도와 매우 큰 소음을 발생함. (장탄 수 120발)
15. 볼트 액션(SR - 9탄) : 단발로 쏠 수 있는 매우 정확하고 중 ~ 원거리에서 매우 높은 데미지 (초원거리에서 높은 데미지, 근거리에서 보통 데미지), 느린 재장전 속도와 느린 연사 속도를 가지며, 매우 큰 소음 발생 (장탄 수 5발)
16. 대물 저격총(SR - 9탄) : 단발로만 쏠 수 있는 매우 정확하고 원 ~ 초원거리에서 매우 높은 데미지 (이외에는 높은 데미지), 매우 느린 재장전 속도와 매우 느린 연사 속도, 매우 큰 소음 발생 (장탄 수 1발)
17. 사냥총(SR - 7탄) : 단발로만 쏠 수 있는 정확한 중거리에서 높은 데미지 (나머지는 조금 높은 데미지 발생), 볼트 액션보다는 빠르지만 카빈보다 느린 연사 속도, 빠른 재장전 속도를 가지며, 적은 소음이 발생 (장탄 수 6발)

부무기
1. 소음 권총(권총 - 4탄) : 기본적으로 소음기가 내장되어있는 소음이 발생하지 않는 권총으로 매우 정확하고, 단발 사격이 가능한 권총으로, 방어구가 없는 상대에게 높은 데미지를 주지만, 거리가 중거리 이상이거나 방어구가 있는 상대에게는 매우 낮은 데미지를 주는 총기 (장탄 수 12발)
2. 숏 배럴(샷건) : 가벼운 샷건으로, 발당 4개의 탄환이 매우 넓게 퍼지는 근접용 무기. 매우 큰 소음이 발생하고, 탄환 당 낮은 무기가 발생하며, 빠른 재장전 속도와 적당한 연사 속도를 가짐. (장탄 수 2발)
3. 매그넘(권총 - 4탄) : 소음이 크게 발생하는 근거리 내에서 높은 데미지를 주는 단발 사격 가능한 권총, 근거리내에서는 높은 명중률이지만, 재장전 속도가 느리고, 연사 속도가 떨어짐. (장탄 수 6발)
4. 기관권총(권총 - 4탄) : 매우 빠른 연사 속도와 낮은 데미지를 주는 초근거리 용도의 권총으로, 방어구가 없는 대상에게 높은 데미지를 줄 수 있는 총기로 매우 낮은 정확도를 가진 총기 (장탄 수 12발)
5. 자동권총(권총 - 4탄) : 3점사 / 연발 가능한 권총으로, 빠른 연사속도와 낮은 정확도를 가진 총기로 근거리 내에서 적당한 데미지를 주지만 중거리이상에서는 매우 낮은 데미지를 주는 총기 (장탄 수 12발)
6. 프로토타입(권총 - 4탄) : 단발 사격이 가능한 권총으로 중거리 내에서 적당한 데미지를 주며, 연사 속도가 적당한 권총으로 조금 느린 재장전 속도와 조금 느린 연발 속도를 가짐. (장탄 수 8발)

#### 관통 데미지 계산
```typescript
interface Cover {
  type: 'none' | 'soft' | 'medium' | 'hard' | 'solid';
  damageReduction: number;  // 0.0 ~ 1.0
}

function applyCoverPenetration(damage: number, weapon: Weapon, cover: Cover): number {
  // 관통 가능 여부 체크
  if (!canPenetrate(weapon.penetration, cover.type)) {
    return 0; // 완전 차단
  }
  
  // 관통 시 데미지 감소
  const reduction = cover.damageReduction * (1 - weapon.penetrationBonus);
  return damage * (1 - reduction);
}

function canPenetrate(weaponPen: number, coverType: string): boolean {
  const coverStrength = {
    'none': 0,
    'soft': 1,
    'medium': 2,
    'hard': 3,
    'solid': 999
  };
  return weaponPen >= coverStrength[coverType];
}
```

## 🤖 AI 플레이어 (봇)

### 봇 참여 규칙
- 인원 미달 시 자동으로 봇 추가
- **최소 실제 플레이어 비율** : 최소 실제 플레이어는 아직 고려X, 서버를 여는 사람이 게임 시작 결정해서, 인원수, 실제 사람 수를 설정하면 나머지 자리를 AI로 채우도록 할 것
- 봇 난이도는 남은 플레이어 실력에 맞춤 `[논의 필요]` : 당장은 원거리에서는 시야 내에 들어오면 천천히 조준 후 사격, 중거리에서는 시야 혹은 소음 발생 시 해당 지역으로 시야를 밝히고 짧은 시간 안에 조준 후 사격, 근거리에서는 시야 내에 있을 시 빠르게 조준 후 사격

### 봇 표시
- 봇 여부 표시 `[논의 필요: 표시 여부]` - 당장은 랜덤한 번호 부여 / 차후에 논의
- 킬 로그에서 구분 `[논의 필요]` - 킬로그에 해당 아이디 보이도록 할 것

> 📝 봇 AI 상세는 `npcBook.md` 참조

## 🔧 관리자 규칙 (Admin Rules)

- 일단은 로컬 서버를 여는 사람이 관리자 및 플레이어 역할을 맡으며 게임 서버가 되어서 초대 코드를 발송, 게임 메인에 초대 코드를 입력하는 사람이 해당 방에 접근하도록 할 것.

### 게임 설정 (서버 측)
| 설정 | 기본값 | 조정 가능 범위 |
|------|--------|---------------|
| 최대 플레이어 | 32 | 8-32 | // 이건 먼저 32명으로 정하고, 남은 인원은 AI로 채울것, 나중에 고려할 예정
| 게임 시간 제한 | 15분 | 5-30분 | // 이건 아직은 무제한으로 두고, 나중에 게임 시간을 서버장이 고를 수 있도록 할 것
| 아이템 스폰율 | 100% | 50-200% | // 이건 차후에 고려, 당장은 100%로 고정
| 자기장 속도 | 100% | 50-200% | // 이것도 차후에 고려, 당장은 100%로 고정

### 제재 시스템 `[논의 필요]` : 이건 당장은 하지 않을것
```
- 핵/치팅 감지
- 신고 시스템
- 일시 정지 / 영구 밴
- 불량 행위 기준
```

### 관전 모드 `[논의 필요]` : 사망 후에 본인을 잡은 유저의 화면으로 고정하여 관전을 허용할 예정, 단, 시야는 대상과 동일해야 함.
```
- 사망 후 관전 허용?
- 자유 시점 vs 플레이어 시점
- 관전 딜레이 (스트림 스나이핑 방지) : 당장은 고려하지 않을 것
```

## 📊 통계 및 기록

### 게임 내 표시
- 현재 생존자 수 : 우상단에 볼드체로 표시할 것
- 본인 킬 수 : in-game 중에는 표시하지말고 게임이 끝나거나 게임오버된 경우에 통계로 표시
- 자기장 다음 이동까지 시간
- 미니맵 (안전 구역 표시) : 이건 특정 키를 누르면 미니맵을 실시간으로 크게 볼 수 있어야 하고, 크게 봤을 때도 자기장 영역이나 실제 지도와 동일하게 표시되어야 함.

### 게임 종료 후 통계
| 항목 | 설명 |
|------|------|
| 최종 순위 | 1위 ~ 32위 |
| 킬 수 | 직접 처치한 플레이어 수 |
| 어시스트 | 처치 기여 `[논의 필요]` | : 이건 최종적으로 죽었을 때 전체 체력의 50%이상 처치에 기여한 경우만 해당
| 총 데미지 | 가한 데미지 합계 | : 방어막이나 기타 체력이 아닌 수치를 깍아도 데미지로 합산
| 생존 시간 | 게임 내 생존 시간 | : 당장은 고려X
| 이동 거리 | `[논의 필요]` | : 당장은 고려X

추가로 사용한 무기 별로 킬 수, 어시스트 수, 총 데미지를 통계로 보여줄 것
