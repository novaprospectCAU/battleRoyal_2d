## 📌 이 문서의 목적

이 문서는 게임의 **시각적 에셋 규격, 디버그/프로덕션 모드, 스프라이트 구조**를 정의합니다.

---

## 🎯 핵심 원칙

### 에셋 독립성
```
✅ 에셋이 없어도 게임이 동작해야 함

모든 시각 요소는 두 가지 모드 지원:
1. 디버그 모드: 도형/색상으로 표현
2. 프로덕션 모드: 실제 에셋 사용
```

### 듀얼 모드 시스템

```typescript
// 에셋 로더 예시
interface AssetConfig {
  mode: 'debug' | 'production';
}

class AssetManager {
  private mode: 'debug' | 'production';
  
  getPlayerSprite(playerId: string): Renderable {
    if (this.mode === 'debug') {
      return new DebugCircle({ radius: 16, color: 'blue' });
    }
    return new Sprite('player.png');
  }
}
```

## 🔷 디버그 모드

### 목적
- 에셋 없이 게임 로직 테스트
- 히트박스/충돌 영역 시각화
- 빠른 프로토타이핑

### 디버그 렌더링 규칙

| 요소 | 도형 | 색상 | 크기 |
|------|------|------|------|
| **플레이어 (본인)** | 원 | 파란색 | 16px 반지름 |
| **플레이어 (타인)** | 원 | 빨간색 | 16px 반지름 |
| **플레이어 (AI)** | 원 | 주황색 | 16px 반지름 |
| **사망한 플레이어** | 원 | 회색 | 16px 반지름 |
| **무기** | 사각형 | 노란색 | 12x8px |
| **아이템 (탄약)** | 사각형 | 갈색 | 8x8px |
| **아이템 (회복)** | 사각형 | 초록색 | 10x10px |
| **아이템 (방어구)** | 사각형 | 하늘색 | 10x10px |
| **투사체** | 원/선 | 노란색 | 4px 반지름 |
| **벽 (완전)** | 사각형 | 검정색 | 타일 크기 |
| **엄폐물 (연질)** | 사각형 | 연두색 | 가변 |
| **엄폐물 (중질)** | 사각형 | 갈색 | 가변 |
| **엄폐물 (경질)** | 사각형 | 회색 | 가변 |
| **문 (닫힘)** | 사각형 | 갈색 + 테두리 | 타일 너비 |
| **문 (열림)** | 선 | 갈색 | 타일 너비 |
| **창문** | 사각형 | 투명 + 파란 테두리 | 타일 너비 |
| **자기장 경계** | 원 | 빨간색 (반투명) | - |
| **안전 구역** | 원 | 흰색 (테두리) | - |

### 디버그 오버레이

```
디버그 모드에서 추가로 표시:
- 히트박스 윤곽선
- 좌표 그리드
- FPS/틱 카운터
- 네트워크 지연 시간
- 플레이어 ID
- 체력 바
```

## 👤 플레이어 에셋

### 크기 규격

```
기준: 1 타일 = 플레이어 가로 × 2

플레이어 크기:
- 가로: 16px (예상, 타일 32px 기준)
- 세로: 24px (약간 세로로 긴 비율)

히트박스:
- 단일 사각형/원형
- 크기: 16 × 24px 또는 반지름 12px
```

### 방향

```
쿼터뷰 8방향:
1. 북 (↑)
2. 북동 (↗)
3. 동 (→)
4. 남동 (↘)
5. 남 (↓)
6. 남서 (↙)
7. 서 (←)
8. 북서 (↖)

또는 4방향 + 좌우 반전으로 단순화 가능
```

### 애니메이션 상태

| 상태 | 프레임 수 | 설명 |
|------|----------|------|
| **대기 (Idle)** | 4 | 서있는 상태 |
| **걷기 (Walk)** | 6 | 이동 중 |
| **달리기 (Run)** | 6 | 빠른 이동 |
| **공격 (Attack)** | 3 | 무기 사용 |
| **재장전 (Reload)** | 4 | 재장전 중 |
| **피격 (Hit)** | 2 | 데미지 받음 |
| **사망 (Death)** | 4 | 사망 애니메이션 |
| **창문 넘기** | 4 | 창문/반벽 넘는 중 |

## 🔫 무기 에셋

### 크기 규격

```
무기 크기 (플레이어 손에 들린 상태):
- 권총류: 8 × 6px
- SMG: 12 × 6px
- 소총: 16 × 6px
- 샷건: 14 × 7px
- MG: 18 × 8px
- SR: 20 × 6px

드랍 아이템 (바닥에 있을 때):
- 일괄: 16 × 16px (아이콘 형태)
```

### 발사 이펙트

```
머즐 플래시:
- 크기: 8 × 8px
- 프레임: 2-3
- 무기 앞쪽에 표시

탄피 이펙트 (선택):
- 크기: 4 × 4px
- 프레임: 3-4
- 측면으로 튀어나감
```

## 🏢 맵/건물 에셋

### 타일 크기

```
기본 타일: 32 × 32px (플레이어 가로 × 2)

타일 종류:
- 지면 타일 (잔디, 흙, 아스팔트 등)
- 벽 타일 (건물 외벽, 내벽)
- 바닥 타일 (건물 내부)
- 장식 타일 (균열, 풀 등)
```

### 건물 구성

```
건물 = 타일 조합

벽 타일 종류:
- 직선 (상/하/좌/우)
- 코너 (4방향)
- T자 (4방향)
- 십자
- 문 (열림/닫힘)
- 창문

내부 오브젝트:
- 가구 (책상, 침대, 소파 등)
- 상자/컨테이너
- 장식물
```

### 엄폐물 에셋

| 종류 | 크기 | 특징 |
|------|------|------|
| 나무 상자 | 32 × 32px | 연질 |
| 금속 드럼통 | 32 × 32px | 중질 |
| 차량 | 64 × 96px | 중질 |
| 콘크리트 블록 | 32 × 32px | 경질 |
| 컨테이너 | 64 × 32px | 경질 |

## 🌐 자기장 시각화

### 자기장 렌더링

```
경계선:
- 색상: 붉은색 (#FF4444)
- 두께: 3-5px
- 스타일: 실선 또는 글로우 효과

자기장 내부 (위험 지역):
- 색상: 붉은 색조 오버레이
- opacity: 0.15 ~ 0.2
- 펄스 효과 (선택)

자기장 밖 플레이어:
- 화면 전체 붉은 색조
- opacity: 0.1
- 가장자리 비네팅 효과 (선택)
```

## 📏 에셋 네이밍 규칙

### 파일 이름 형식

```
{category}_{name}_{variant}_{state}.png

예시:
- player_default_n_idle.png
- weapon_rifle_assault.png
- item_ammo_9mm.png
- tile_ground_grass.png
- effect_explosion_01.png
- ui_hud_healthbar.png
```

### 폴더 구조

```
assets/
├── sprites/
│   ├── player/
│   │   ├── player_default.png (스프라이트 시트)
│   │   └── player_default.json (애니메이션 데이터)
│   ├── weapons/
│   ├── items/
│   └── effects/
│
├── tiles/
│   ├── ground/
│   ├── walls/
│   └── objects/
│
├── ui/
│   ├── hud/
│   ├── menu/
│   └── icons/
│
└── audio/  (→ audioBook.md)
```

## 🔄 에셋 로딩

### 로딩 전략

```typescript
// 에셋 매니페스트
interface AssetManifest {
  sprites: {
    player: { path: string; animations: AnimationDef[] };
    weapons: { [key: string]: string };
    // ...
  };
  tiles: { [key: string]: string };
  ui: { [key: string]: string };
}

// 로딩 순서
1. 필수 UI (로딩 화면)
2. 플레이어 스프라이트
3. 무기/아이템
4. 맵 타일
5. 이펙트 (백그라운드)
```

### 폴백 (Fallback)

```typescript
// 에셋 로드 실패 시 디버그 모드로 폴백
async function loadAsset(path: string, fallback: DebugRenderable) {
  try {
    return await loadImage(path);
  } catch (error) {
    console.warn(`Asset not found: ${path}, using debug mode`);
    return fallback;
  }
}
```
